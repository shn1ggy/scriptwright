Courier Prime font files go here (downloaded by `npm install`, see scripts/fetch-fonts.mjs):

- CourierPrime-Regular.ttf
- CourierPrime-Bold.ttf
- CourierPrime-Italic.ttf
- CourierPrime-BoldItalic.ttf
- OFL.txt (license)

They are used by the editor and embedded in exported PDFs. Without them, Scriptwright
falls back to Courier and says so in the export workspace.
