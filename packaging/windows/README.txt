Scriptwright for Windows (test build)

1. Unzip this folder somewhere (e.g. Documents).
2. Double-click "Run Scriptwright.cmd".
   The first start downloads the Electron runtime (about 130 MB) from GitHub, checks it and starts the app.
   Later starts take a second.
3. If Windows shows "Windows protected your PC": More info > Run anyway (the files are not signed).

Updates: replace the "app" folder with the new one and run "Run Scriptwright.cmd" again.
